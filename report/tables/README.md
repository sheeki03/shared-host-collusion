# Supplementary research tables

These are the twenty tables cited by the manuscript and supplement. The Markdown retains all generated values, headings and explanatory notes. CSV files contain the same table cells; a file with several tables may contain repeated headers and differing column counts, so these are table exports rather than raw analysis datasets.

The archive excludes raw Inspect logs, provider request/error payloads, classifier keys, individual review sheets and private host configuration. The human validation was not performed; the separately disclosed AI review is not human validation. Account-wide spending reconciliation remains deferred (D38).

`manifest.json` records the statistical source revision and SHA-256 of each published file. Full methods, limitations and deviations are in the report and `prereg/DEVIATIONS.md`.
